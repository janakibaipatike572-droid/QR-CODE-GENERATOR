# QR Code Generator

A simple Python program that generates a QR code from user-entered text or a URL and saves it as an image.

## Features

* Generate QR codes
* Supports text and URLs
* Saves the QR code as a PNG image

## Requirements

* Python 3.x
* qrcode library
* Pillow library

## Installation

```bash
pip install qrcode[pil]
```

## How to Run

1. Run the program.
2. Enter text or a URL.
3. The QR code is saved as `qrcode.png`.
